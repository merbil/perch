# Perch

An always-on-top mini player for the Mac. It lives in the menu bar, sticks to the edges of your screen, and controls Spotify.

Where you put it picks its look: a pill on an edge, a tile in a corner, a card in the middle, or a Winamp-style deck hanging from the menu bar.

## Build

```bash
scripts/build-app.sh
```

This builds `build/Perch.app`. Run it with `--demo` to try it with a fake player.

Needs macOS 14 or later.
